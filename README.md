# mkelcik/homebrew-tap

Homebrew casks for [mkelcik](https://github.com/mkelcik)'s apps.

## Do Not Forget

Your next meeting, one glance away: a tray app with Google Calendar.
[Website](https://mkelcik.github.io/do-not-forget/) · [Source](https://github.com/mkelcik/do-not-forget)

```bash
brew install --cask mkelcik/tap/do-not-forget
```

Apple Silicon, macOS 11 or later. The app updates itself; `Casks/do-not-forget.rb` is bumped
by the app's release workflow.
